# animegame_Localify

LiveContainer Tweaks + JIT 환경에서 사용할 native localify 빌드 자료를 정리한 저장소입니다.

## 포함 항목

- `animegame_Native_Localify_Kit/`: native dylib 빌드 키트
- 빌드 스크립트, native hook 소스, translation blob 생성 스크립트
- 로컬에서 준비해야 하는 `g.js` 안내 문서

## 문서

- [한국어 README](animegame_Native_Localify_Kit/README_KO.md)
- [English README](animegame_Native_Localify_Kit/README_EN.md)

## 제외 항목

다음 파일은 저장소에 포함하지 않습니다.

- IPA 파일
- 빌드된 dylib
- 로그 파일
- `g.js` 원본
- build/out 산출물
